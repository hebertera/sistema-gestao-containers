Sistema de Gestão de Containers

Projeto desenvolvido em Python + MySQL com o objetivo de aplicar conceitos de programação e banco de dados em um contexto de operações portuárias.

Tecnologias utilizadas

* Python
* MySQL
* Git
* GitHub
* Visual Studio Code

Funcionalidades

<img width="727" height="912" alt="validações" src="https://github.com/user-attachments/assets/f4de398d-603d-405d-bb86-7c71e0060c0d" />

O sistema permite:

* Cadastrar containers
* Consultar registros
* Alterar dados
* Excluir registros
* Validar informações dos containers
* Armazenar os dados em banco de dados MySQL

Banco de dados

O projeto utiliza MySQL para armazenar as informações dos containers.

Objetivo

Este projeto faz parte da minha evolução nos estudos de Engenharia de Software, Python, Backend e Banco de Dados, buscando unir conhecimentos de tecnologia com minha experiência em operações portuárias.
